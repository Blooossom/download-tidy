# 줍줍

다운로드 파일을 분류해서 살펴보고, 검색·미리보기한 뒤 선택한 파일을 종류별 폴더로 옮기는 macOS 앱입니다. SwiftUI + AppKit으로 만들었으며 외부 패키지, 계정, 서버 없이 동작합니다.

## 실행

```sh
git clone https://github.com/Blooossom/download-tidy.git
cd download-tidy
zsh scripts/build-app.sh
open "dist/줍줍.app"
```

빌드된 앱을 Finder에서 더블클릭해도 됩니다. 로컬 개발용 ad-hoc 서명 빌드이며 공증된 배포본은 아닙니다. 빌드에는 Swift 6 이상과 macOS SDK가 필요합니다. 배포 대상은 macOS 13 이상으로 설정했으며 실제 검증 환경은 Apple Silicon / macOS 27.0.1입니다.

## 사용 흐름

1. 처음 실행하면 `다운로드 폴더 연결`을 누르고 대상 폴더를 선택합니다. 선택 창은 `~/Downloads`에서 시작합니다. 이후에는 선택한 폴더를 기억하며 `폴더 변경`으로 바꿀 수 있습니다.
2. 왼쪽 분류, 기간, 이름·크기·추가일 정렬로 파일을 살펴봅니다. 파일명은 한글 유니코드 조합 차이와 대소문자를 구분하지 않고 검색합니다.
3. 파일 행을 클릭하면 Quick Look 미리보기가 나타납니다. 더블클릭하거나 `열기`를 누르면 연결된 앱에서 엽니다. Finder에서 보기와 다른 앱으로 파일 끌어놓기도 지원합니다.
4. 체크박스로 정리할 파일을 고릅니다. 목록 상단 체크박스는 현재 검색·필터 결과의 정리 가능한 파일만 선택합니다. 상단 `종류별 정리 제안`은 전체 정리 가능한 파일을 선택합니다. 첫 조회 때는 아무 파일도 선택하지 않습니다.
5. `정리 미리보기`에서 `종류별 폴더` 또는 `직접 지정한 폴더`를 고릅니다. 직접 지정할 때는 새 폴더 이름을 입력하거나 `기존 폴더 선택`에서 고를 수 있습니다. 선택한 파일 전부를 지정한 한 폴더에 모으며, 새 폴더는 실제 이동을 실행할 때 만듭니다.
6. 원본과 목적지의 전체 경로를 확인한 뒤 `N개 파일 이동`을 누릅니다.
7. `정리 기록`에서 실행별 결과와 실패 이유를 확인하고 해당 정리를 되돌릴 수 있습니다.

창을 닫아도 메뉴 막대 아이콘은 남습니다. 여기서 최근 파일 8개를 열거나 메인 창, 정리 기록을 다시 열 수 있습니다. 메뉴의 `종료` 또는 ⌘Q로 완전히 종료합니다. 실행 중 15초마다 목록을 새로 읽으며, 수동 새로고침은 ⌘R입니다.

## 탐색과 검색 범위

- 선택한 폴더 바로 아래의 파일·폴더를 표시합니다. 기본 분류 폴더(문서, 이미지, 동영상, 오디오, 압축파일, 설치파일)와 앱에서 정리에 사용한 커스텀 폴더의 바로 아래 파일도 함께 표시해 정리 후 계속 찾을 수 있습니다. 그 밖의 폴더 내부는 탐색하지 않습니다.
- 하위 파일에는 `정리됨` 표시가 붙으며 다시 정리하지 않습니다. 폴더, 앱 번들, 숨김 파일, 별칭, 심볼릭 링크는 이동 대상이 아닙니다. 미분류 파일은 직접 지정한 폴더로 정리할 수 있으며, 종류별 자동 제안에서는 제외합니다.
- 내용 검색: 텍스트가 있는 PDF는 20MB 이하 / 앞 80쪽 / 약 50만 글자까지, UTF-8 TXT·MD·CSV·TSV·LOG는 1MB 이하를 지원합니다. 스캔 PDF의 OCR, HWP·HWPX·Office 파일 본문, 이미지 내용 검색은 지원하지 않습니다. 해당 파일도 파일명으로 검색할 수 있습니다.
- 내용 색인은 검색할 때 메모리에만 만들며 외부 전송하거나 디스크에 저장하지 않습니다. 파일 변경 시 다음 새로고침·검색에서 갱신합니다. `내용 검색`을 끄면 파일명만 검색합니다.
- 날짜 필터는 폴더에 추가된 날짜를 사용하며, macOS가 제공하지 않으면 생성일을 사용합니다. `30일 이전`은 마지막 사용일을 의미하지 않습니다.
- Quick Look 지원 형식은 macOS와 설치된 확장에 따라 다릅니다.

## 파일 이동과 되돌리기

- 선택한 폴더 바로 아래의 분류별 폴더 또는 직접 지정한 폴더로 이동합니다. 직접 지정한 폴더는 정리 기록을 통해 재실행 후에도 기억합니다. 폴더 이름에 경로 구분자를 넣거나, 숨김 폴더·앱·패키지·링크를 목적지로 지정할 수 없습니다. 실행 버튼을 누르기 전에는 파일을 옮기거나 목적지 폴더를 만들지 않습니다. 삭제 기능은 없습니다.
- 이름 충돌은 `이름 (1).확장자`로 미리 제안합니다. 검토 후 새 충돌이 생기면 건너뜁니다. 시스템의 배타적 rename을 사용해 기존 파일을 덮어쓰지 않습니다. 다른 볼륨으로의 이동은 수행하지 않습니다.
- 다운로드 임시 확장자, Office 임시 잠금 파일, 잠긴 파일, 최근 3초 이내에 수정된 파일을 보류합니다. 이동 전 1초 간격으로 파일 식별자·크기·수정시각이 동일한지 다시 확인합니다. 다른 앱이 파일을 열어 두었는지 완벽하게 알아낼 수는 없습니다.
- 이동 전에 원본·목적지·파일 식별 정보·대기 상태를 기록하고 각 파일마다 결과를 저장합니다. 기록 저장에 실패하면 작업을 멈춥니다. 중간 종료 시 다음 실행에서 양쪽 위치를 확인하고 상태를 복구합니다. 불확실한 상태는 기록에 남겨 수동 확인하도록 합니다.
- 되돌리기는 원본 경로가 비어 있고 이동한 파일의 식별자·크기·수정시각이 동일할 때만 가능합니다. 충돌·변경된 파일은 건너뛰고 이유를 기록합니다. 가능한 다른 파일들은 계속 처리합니다. 앱이 만든 빈 분류 폴더는 남깁니다.
- 기록은 파일 내용의 백업이 아닙니다. 재실행 후에도 보관하며 자동 삭제하지 않습니다. 기록 파일이 손상되면 원본 기록을 보존하고 이동 기능을 잠급니다.

앱 이름을 ‘줍줍’으로 변경했으며 기존 버전의 폴더 설정과 정리 기록을 이어서 사용합니다. GitHub 저장소 주소와 내부 저장 경로는 `download-tidy` / `DownloadTidy`를 유지합니다.

저장 위치:

- 이동 기록: `~/Library/Application Support/DownloadTidy/history.json`
- 선택 폴더와 창 위치: macOS UserDefaults

## 검증

```sh
zsh scripts/test.sh
```

임시 폴더로 분류·읽기 전용 탐색, 이름 충돌, 선택 파일 이동, 재실행 후 기록과 되돌리기, 검토 후 원본 변경·목적지 충돌, 부분 실패, 변경된 파일·원본 충돌 보호, 심볼릭 링크 목적지 차단, 기록 저장 실패, 손상 기록 보존, 중단된 이동·되돌리기 복구, 한글 정규화·내용 검색을 검증합니다. 현재 Command Line Tools에 XCTest가 없어 Swift Testing을 사용하며 테스트 매크로 경로를 스크립트에서 지정합니다.

UI 확인용 별도 폴더를 사용할 수 있습니다. 이 모드의 기록은 해당 폴더의 `.tidy-test-state` 아래에 저장됩니다.

```sh
open -n "dist/줍줍.app" --args --demo /절대/경로/테스트폴더
```

## 첫 버전에서 보류한 기능

사용자 지정 분류 규칙, 선택한 폴더 바깥으로의 이동, 유지 표시, 파일별 개별 되돌리기, 자동 이동, 중복 파일 삭제, 로그인 시 자동 시작, 모든 하위 폴더 검색은 아직 포함하지 않았습니다. 이 문서가 현재 구현 범위입니다.
